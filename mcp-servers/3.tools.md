# 3. MCP tools for this chatbot

We need only three tools.

## Tool 1: `search_action_items`

Used for questions such as:

```text
"Find kickoff templates"
"List the latest HIGH-priority templates"
```

Inputs:

```text
search: optional text
priority: optional LOW, MEDIUM, or HIGH
limit: 1 to 50
```

MongoDB query built by the server:

```python
query = {
    "action_name": {"$regex": re.escape(search), "$options": "i"},
    "priority": priority,
}
```

The server builds this query. The LLM never sends raw MongoDB operators.

## Tool 2: `get_action_item`

Used for:

```text
"Explain action item 700b0b39-..."
```

Input: `action_library_id`

Query:

```python
{"action_library_id": action_library_id}
```

## Tool 3: `get_action_item_counts`

Used for:

```text
"How many LOW, MEDIUM, and HIGH priority templates exist?"
```

It runs a fixed MongoDB aggregation grouped by `priority`.

## Tools we intentionally avoid

```text
execute_mongo_query
run_aggregation
delete_action_item
update_action_item
```

These give the model too much power or are unnecessary for a question-answering chatbot.

## Tool descriptions matter

The LLM uses the name, description, and input types to decide which tool to call. A useful description says exactly what the tool returns and when it should be used.

```python
@mcp.tool()
async def get_action_item(action_library_id: str) -> dict:
    """Get one Action Items Library template by its exact library ID."""
```
