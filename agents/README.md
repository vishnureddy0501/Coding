## Main Idea

Do not use an agent only to generate isolated code snippets. Give it a complete and verifiable outcome:

```text
Investigate → Plan → Implement → Test → Review
```

Your first improvements should be:

1. Write clearer task prompts.
2. Add an `AGENTS.md` file to your main repository.
3. Require verification for every code change.
4. Connect one useful read-only MCP service.
5. Turn repeated workflows into skills.
