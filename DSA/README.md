# DSA Interview Question Tracker

This list contains the most useful DSA questions for frontend and backend software-engineering interviews.

Questions are intentionally ordered as:

1. **Medium** — highest interview value; complete these first.
2. **Easy** — important foundations and quick revision.
3. **Hard** — selected questions only; learn after the main list.

## How to practice each question

For every problem, be able to explain:

1. The simple or brute-force approach.
2. Why it is slow.
3. The optimized approach and its pattern.
4. Time and space complexity.
5. Important edge cases.

Do not try to memorize every line. Learn how to recognize the pattern.
