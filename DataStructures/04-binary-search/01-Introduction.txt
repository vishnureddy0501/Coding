when to use binary search:
-----------------------------
your answer b/w x and y. and they asked to maximize or minimize something. then it is always a binary search problem.


1539. Kth Missing Positive Number
--------------------------------
mind blowing logic (analyze using pen, paper)

Binary search on answer - template:
-----------------------------------
    int low = minPossible, high = maxPossible, ans = -1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // avoids overflow of (low + high)
        if (isPossible(mid)) { ans = mid; high = mid - 1; }   // minimize: try smaller
        else low = mid + 1;
    }
    (for maximize: on success ans = mid, low = mid + 1)

Classic problems: Koko Eating Bananas, Minimum Days to Make Bouquets, Capacity to Ship Packages,
Aggressive Cows, Book Allocation, Split Array Largest Sum, Painter's Partition, Median of 2 Sorted Arrays.
