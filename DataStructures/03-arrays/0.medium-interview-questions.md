## Patterns you must recognize

### Hash map

Use it when you need to quickly find whether a value or previous prefix sum exists, or when you need to count frequencies.

Common questions: Top K Frequent Elements and Subarray Sum Equals K.

### Two pointers

Usually useful when the array is sorted or when two ends of the array must be compared.

Common questions: 3Sum and Container With Most Water.

### Sliding window

Useful for a continuous subarray when the window can be expanded and reduced.

Common questions: Minimum Size Subarray Sum and Max Consecutive Ones III.

### Prefix sum

Use it when a question repeatedly asks about the sum of a subarray.

```text
subarray sum from left to right
= prefix[right] - prefix[left - 1]
```

### Greedy

At every position, keep only the best information needed for the future.

Common questions: Jump Game and Gas Station.

### Kadane's algorithm

At every index, decide whether to extend the previous subarray or start a new one.

Common question: Maximum Subarray.

### Intervals

Sort intervals by their starting point before comparing or merging them.

Common questions: Merge Intervals, Insert Interval, and Non-overlapping Intervals.

## Interview preparation rule

For every question, be able to explain:

1. The brute-force approach.
2. Why it is slow.
3. The pattern used by the optimized approach.
4. Time and space complexity.
5. Important edge cases such as an empty array, duplicates, negative values, and integer overflow.
