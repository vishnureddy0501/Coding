DFS (Depth First Search) - go as deep as possible, then backtrack (recursion / stack)
-----------------------------------------------------------------------------------
Time: O(V + E)   Space: O(V) recursion stack

Standard code:

    void dfs(vector<vector<int>>& g, int node, vector<int>& visited, vector<int>& res) {
        visited[node] = 1;
        res.push_back(node);
        for (int nb : g[node]) {
            if (!visited[nb]) dfs(g, nb, visited, res);   // pass nb, NOT the loop index
        }
    }


Connected components (Code360 "DFS Traversal"):
------------------------------------------------
Run DFS from every unvisited node. Each DFS call from the outer loop = one component.

    vector<vector<int>> depthFirstSearch(int n, int e, vector<vector<int>>& edges) {
        vector<vector<int>> g(n);
        for (auto &ed : edges) {
            g[ed[0]].push_back(ed[1]);
            g[ed[1]].push_back(ed[0]);
        }
        vector<int> visited(n, 0);
        vector<vector<int>> res;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                vector<int> comp;
                dfs(g, i, visited, comp);
                sort(comp.begin(), comp.end());   // Code360 expects each component sorted
                res.push_back(comp);
            }
        }
        return res;
    }


Common mistakes:
----------------
1. for (int i = 0; i < g[node].size(); i++) dfs(g, i, ...)   -> i is a position, the neighbour is g[node][i].
2. Marking the neighbour visited before calling dfs is redundant (dfs marks it itself).
3. Very deep graphs (1e5 nodes in a line) can overflow the recursion stack -> use BFS or an explicit stack.


BFS vs DFS - when to use which:
-------------------------------
    Shortest path in unweighted graph  -> BFS
    Level / minimum steps              -> BFS
    Cycle detection, components        -> either
    Topological sort, SCC, bridges     -> DFS (needs finish order / recursion)
    Explore all paths / backtracking   -> DFS
