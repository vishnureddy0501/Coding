for tress - we can use bfs/ dfs for finding shortest path.
	we can use dfs only if we have unique path to reach a node.

finding shortest path using dfs is applicable only in trees. because in trees we have unique path from a node to another node.


for graphs, for finding the shortest path we have to use bfs only.


Dfs -> runs in exponential time   (only when you try EVERY path to find the shortest one)
Bfs -> runs in polynomial time.

Correction: a normal DFS traversal (with a visited array) is O(V + E), same as BFS.
It becomes exponential only when you un-mark visited while backtracking to explore all paths.

Hence, for shortest path in unweighted graphs, prefer Bfs over Dfs.
