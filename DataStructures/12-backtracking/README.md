# Backtracking — Interview Roadmap

Backtracking means:

```text
Choose -> Explore -> Undo
```

Use it when a problem asks for:

- All subsets, combinations, or permutations.
- All valid arrangements.
- A path through a grid.
- A solution that must follow many rules.
