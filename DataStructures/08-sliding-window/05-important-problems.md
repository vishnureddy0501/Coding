# 5. Important Interview Problems

Solve in this order:

| # | Problem | Pattern |
|---:|---|---|
| 1 | Maximum sum subarray of size K | Fixed window |
| 2 | LeetCode 3 — Longest Substring Without Repeating Characters | Longest valid window |
| 3 | LeetCode 1004 — Max Consecutive Ones III | At most K invalid values |
| 4 | LeetCode 904 — Fruit Into Baskets | At most 2 distinct |
| 5 | LeetCode 424 — Longest Repeating Character Replacement | Frequency + longest window |
| 6 | LeetCode 209 — Minimum Size Subarray Sum | Minimum valid window |
| 7 | LeetCode 1358 — Substrings Containing All Three Characters | Counting windows |
| 8 | LeetCode 930 — Binary Subarrays With Sum | `atMost(k) - atMost(k-1)` |
| 9 | LeetCode 1248 — Count Number of Nice Subarrays | Exactly K odds |
| 10 | LeetCode 992 — Subarrays with K Distinct Integers | Exactly K distinct |
| 11 | LeetCode 76 — Minimum Window Substring | Minimum covering window |
| 12 | LeetCode 239 — Sliding Window Maximum | Monotonic deque |

Minimum revision: Longest Substring Without Repeating, Max Consecutive Ones III, Binary Subarrays With Sum, K Distinct Integers, and Minimum Window Substring.
