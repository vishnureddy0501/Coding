# Trees — Interview Revision

## Concepts to Know First

### Tree Terminology

- **Root:** topmost node
- **Leaf:** node with no children
- **Height:** longest path from a node to a leaf
- **Depth:** distance from the root to a node
- **Subtree:** a node and all its descendants
- **Balanced tree:** left and right subtree heights differ by at most one at every node

### Traversals

| Traversal | Order | Common use |
| --- | --- | --- |
| Preorder | Root, left, right | Copy or serialize a tree |
| Inorder | Left, root, right | Sorted order in a BST |
| Postorder | Left, right, root | Compute information from children |
| Level order | Level by level using BFS | Views, width, and shortest level distance |

### Complexity

Most tree problems visit every node:

- Time: `O(n)`
- Recursive space: `O(h)`, where `h` is tree height
- A balanced tree has `h = O(log n)`.
- A skewed tree has `h = O(n)`.

## Most Important Interview Questions

Complete the questions in this order. The starred problems are the highest priority.

### 1. Traversal and Basic Recursion

1. ⭐ Binary Tree Preorder Traversal
2. ⭐ Binary Tree Inorder Traversal
3. ⭐ Binary Tree Postorder Traversal
4. ⭐ Binary Tree Level-Order Traversal
5. Maximum Depth of Binary Tree
6. Same Tree
7. Symmetric Tree
8. Invert Binary Tree

**Pattern:** Decide what the recursive function should return, solve the left and right subtrees, and combine their results.

### 2. Height-Based Problems

1. ⭐ Diameter of Binary Tree
2. ⭐ Balanced Binary Tree
3. ⭐ Maximum Path Sum
4. Minimum Depth of Binary Tree

**Pattern:** Use postorder traversal because a parent needs information from its children.

For diameter, calculate subtree height and update the best diameter during the same traversal. Avoid recalculating height for every node.

### 3. Breadth-First Search

1. ⭐ Level-Order Traversal
2. ⭐ Right Side View
3. Zigzag Level-Order Traversal
4. Average of Levels
5. Maximum Width of Binary Tree

**Pattern:** Store the current queue size before processing a level. That size tells you exactly how many nodes belong to the current level.

### 4. Tree Views and Coordinates

1. ⭐ Left and Right Side Views
2. ⭐ Vertical-Order Traversal
3. ⭐ Top View and Bottom View
4. Boundary Traversal

**Pattern:** Assign coordinates to every node:

```text
root        → (x = 0, y = 0)
left child  → (x - 1, y + 1)
right child → (x + 1, y + 1)
```

### 5. Path Problems

1. ⭐ Path Sum
2. ⭐ Binary Tree Maximum Path Sum
3. Root-to-Leaf Paths
4. Path Sum II
5. Count Good Nodes in Binary Tree

**Pattern:** Carry path state downward. Backtrack when storing a shared path collection.

### 6. Lowest Common Ancestor and Distance

1. ⭐ Lowest Common Ancestor of a Binary Tree
2. ⭐ Lowest Common Ancestor of a BST
3. ⭐ All Nodes Distance K in Binary Tree
4. Step-by-Step Directions Between Nodes

**Pattern:** In a normal binary tree, if the left and right recursive calls both find a target, the current node is the LCA.

### 7. Constructing and Serializing Trees

1. ⭐ Construct Binary Tree from Preorder and Inorder
2. Construct Binary Tree from Inorder and Postorder
3. ⭐ Serialize and Deserialize Binary Tree
4. Construct Binary Search Tree from Preorder

**Pattern:** A preorder or postorder traversal identifies the root. Inorder identifies which nodes belong to the left and right subtrees.

### 8. Binary Search Trees

1. ⭐ Search in a BST
2. ⭐ Validate Binary Search Tree
3. ⭐ Kth Smallest Element in a BST
4. ⭐ Lowest Common Ancestor of a BST
5. Insert into a BST
6. Delete Node in a BST
7. BST Iterator
8. Two Sum IV — Input Is a BST
9. Recover Binary Search Tree

**Patterns:**

- Inorder traversal of a BST produces sorted values.
- Validate a BST using an allowed `(minimum, maximum)` range.
- For LCA, move left when both values are smaller and right when both are larger.

### 9. Important Advanced Problems

1. ⭐ Count Complete Tree Nodes
2. Children Sum Property
3. Flatten Binary Tree to Linked List
4. Morris Inorder Traversal
5. Burning Tree
6. Maximum Product of Split Binary Tree

Do these after the core questions. They combine familiar traversal patterns with optimization or careful state management.

## Patterns to Recognize

| Problem signal | Likely approach |
| --- | --- |
| Process children before the parent | Postorder DFS |
| Find a root-to-node path | Preorder DFS with carried state |
| Process nodes level by level | BFS with a queue |
| Need the first or last node of every level | BFS or depth-aware DFS |
| Need columns or views | BFS/DFS with coordinates |
| Need sorted BST values | Inorder traversal |
| Need the kth BST value | Inorder traversal with a counter |
| Need ancestor of two nodes | LCA recursion |
| Need parent movement or distance K | Parent map plus BFS |
| Repeatedly calculating subtree height | Return height from the same DFS |

## Common Mistakes

- Forgetting the `root == nullptr` base case
- Mixing up height measured in nodes and height measured in edges
- Assuming a binary tree is a BST
- Checking only a node's immediate children when validating a BST
- Recomputing subtree height and creating an `O(n²)` solution
- Forgetting to store the queue size before processing a BFS level
- Using global state without resetting it between test cases
- Using `int` when path sums or products require `long long`
- Applying modulo before comparing the true values
- Forgetting that duplicate values can require special ordering rules

## How to Explain a Tree Solution

In an interview, state:

1. What information each recursive call returns
2. The base case
3. How left and right results are combined
4. Whether any global or reference answer is updated
5. Time complexity in terms of nodes
6. Space complexity in terms of tree height

## Quick Templates to Remember

### DFS Thinking

```text
1. Handle the null node.
2. Solve the left subtree.
3. Solve the right subtree.
4. Combine their answers.
5. Return information needed by the parent.
```

### BFS Thinking

```text
1. Push the root into a queue.
2. Record the queue size.
3. Process exactly that many nodes.
4. Push their non-null children.
5. Repeat for the next level.
```
