# Supertest Basics — Syntax You Need First

Supertest sends requests to an Express application without requiring the test to start a server on a real port.

## 1. Required Imports

```js
import request from 'supertest';
import { describe, expect, test } from '@jest/globals';
import app from '../app.js';
```

- `request` comes from Supertest.
- `app` is the exported Express application.
- The `.js` extension is required for local ES module imports.

## 2. Basic Request Shape

```js
const response = await request(app).get('/health');
```

Read it from left to right:

1. `request(app)` selects the Express application.
2. `.get('/health')` sends a GET request to `/health`.
3. `await` waits for the response.
4. `response` contains the returned status, headers, and body.

## 3. Reading the Response

The most useful response properties are:

```js
response.status;
response.body;
response.headers;
response.text;
```

Example:

```js
expect(response.status).toBe(200);
expect(response.body).toEqual({ status: 'ok' });
expect(response.headers['content-type']).toMatch(/json/);
```

Use `response.body` for parsed JSON. Use `response.text` for a plain-text response.

## 4. GET Request

```js
test('returns all users', async () => {
  const response = await request(app).get('/users');

  expect(response.status).toBe(200);
  expect(Array.isArray(response.body)).toBe(true);
});
```

## 5. Path Parameter

Put the value into the URL:

```js
const userId = '123';

const response = await request(app).get(`/users/${userId}`);
```

The backticks create a template string. `${userId}` inserts the value into the URL.

## 6. Query Parameters with `.query()`

```js
const response = await request(app)
  .get('/users')
  .query({ page: 2, limit: 10 });
```

This represents:

```text
GET /users?page=2&limit=10
```

## 7. POST Request with `.send()`

Use `.send()` to provide a JSON request body:

```js
const response = await request(app)
  .post('/users')
  .send({
    name: 'Asha',
    email: 'asha@example.com'
  });
```

The chained lines all belong to one request.

## 8. Request Header with `.set()`

```js
const response = await request(app)
  .get('/profile')
  .set('Authorization', `Bearer ${token}`);
```

`Bearer ${token}` creates a string containing the token.

Set several headers using an object:

```js
const response = await request(app)
  .post('/payments')
  .set({
    Authorization: `Bearer ${token}`,
    'Idempotency-Key': 'order-123'
  })
  .send({ amount: 500 });
```

Property names containing a hyphen must be placed in quotes.

## 9. Other HTTP Methods

```js
await request(app).put('/users/123').send(completeUser);
await request(app).patch('/users/123').send({ name: 'New Name' });
await request(app).delete('/users/123');
```

The syntax is the same; only the HTTP method changes.

## 11. Complete GET Test

```js
import request from 'supertest';
import { describe, expect, test } from '@jest/globals';
import app from '../app.js';

describe('GET /users/:id', () => {
  test('returns an existing user', async () => {
    // Arrange
    const user = await createTestUser({ name: 'Asha' });

    // Act
    const response = await request(app).get(`/users/${user.id}`);

    // Assert
    expect(response.status).toBe(200);
    expect(response.body).toMatchObject({
      id: user.id,
      name: 'Asha'
    });
  });
});
```

`createTestUser()` is an example helper. In a real project, it would insert known data into the test database.

## 12. Complete POST Test

```js
describe('POST /users', () => {
  test('creates a user from valid input', async () => {
    // Arrange
    const body = {
      name: 'Asha',
      email: 'asha@example.com'
    };

    // Act
    const response = await request(app)
      .post('/users')
      .send(body);

    // Assert
    expect(response.status).toBe(201);
    expect(response.body).toMatchObject(body);
    expect(response.body.id).toBeDefined();
  });
});
```

## 13. Validation Test

```js
test('returns 400 when email is missing', async () => {
  const response = await request(app)
    .post('/users')
    .send({ name: 'Asha' });

  expect(response.status).toBe(400);
  expect(response.body.error).toBe('Email is required');
});
```

## Syntax Cheat Sheet

```text
request(app)        select the Express application
.get(path)          send a GET request
.post(path)         send a POST request
.patch(path)        send a PATCH request
.delete(path)       send a DELETE request
.send(body)         send a JSON body
.query(values)      add query parameters
.set(name, value)   add a request header
response.status     read the status code
response.body       read parsed JSON
response.headers    read response headers
response.text       read plain text
```
