# Type annotations vs Pydantic validation

## The main idea

A Python type annotation does not validate or convert a value at runtime.

```python
user: CreateUser = {
    "name": "Vishnu",
    "age": 20,
}
```

`user` is still a normal dictionary. Python does not automatically turn it into a `CreateUser` object.

```python
print(type(user))
# <class 'dict'>
```

The annotation mainly helps editors, type checkers and developers understand the expected type.

## When does Pydantic validate?

Pydantic validates data when you create a model instance:

```python
from pydantic import BaseModel


class CreateUser(BaseModel):
    name: str
    age: int
    email: str


user = CreateUser(
    name="Vishnu",
    age=20,
    email="vishnu@example.com",
)
```

Here, `user` is a real `CreateUser` object and Pydantic validates every field.

```python
print(type(user))
# <class '__main__.CreateUser'>
```

If a required field such as `email` is missing, Pydantic raises a validation error.

## What happens in FastAPI?

```python
@app.post("/users")
def create_user(user: CreateUser):
    return user
```

For this endpoint, FastAPI:

1. Receives the JSON request body.
2. Creates a `CreateUser` model from it.
3. Lets Pydantic validate and convert the values.
4. Calls the endpoint only when validation succeeds.
5. Returns a `422` response when request validation fails.

Inside the endpoint, `user` is a `CreateUser` object rather than a dictionary.

## Required fields

This field is required:

```python
email: str
```

This field is optional and defaults to `None`:

```python
email: str | None = None
```

## Remember

```python
# Only an annotation: no runtime Pydantic validation
user: CreateUser = {"name": "Vishnu", "age": 20}

# Creates the model: Pydantic validation happens
user = CreateUser(
    name="Vishnu",
    age=20,
    email="vishnu@example.com",
)
```

> Python type annotations describe the expected type. Pydantic validates when a model is instantiated. FastAPI automatically instantiates Pydantic models for declared request parameters.
