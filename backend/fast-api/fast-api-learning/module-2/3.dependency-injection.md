# Lesson 3: How routers and service functions work together

The filename says dependency injection because that was the old topic. The `customer-success` project does **not** use FastAPI's `Depends`. It uses direct imports and normal function calls.

The important idea in this project is separation:

```text
main.py
   ↓ includes
feature router
   ↓ includes
endpoint router
   ↓ calls
service function
```

Each layer has one job. Let us build this flow slowly.

## 1. The endpoint router defines an operation

This is similar to the real guided-workflows code:

```python
from typing import Optional

from fastapi import APIRouter, Query

from app.guided_workflows.models import ListGuidedWorkflowsResponse
from app.guided_workflows.services.workflow import list_guided_workflows


router = APIRouter()


@router.get("", response_model=ListGuidedWorkflowsResponse)
async def api_list_guided_workflows(
    tenant: str,
    search: Optional[str] = Query(
        None,
        description="Case-insensitive title search",
    ),
    limit: int = Query(20, ge=1, le=100),
    offset: int = Query(0, ge=0),
):
    return await list_guided_workflows(
        tenant=tenant,
        search=search,
        limit=limit,
        offset=offset,
    )
```

### Why `router = APIRouter()`?

An `APIRouter` is a collection of related endpoints. This file describes guided-workflow endpoints without needing to know how the whole application is created.

This keeps feature code separate from `main.py`.

### Why is the decorator path empty?

```python
@router.get("")
```

The feature router supplies the main path later. An empty string means “use exactly the path supplied by the parent router.”

### Where does `tenant` come from?

```python
tenant: str
```

The parent router's path contains `/{tenant}`. FastAPI sees the same parameter name in the function and supplies the URL value.

For this request:

```text
GET /api/v1/acme/guided_workflows
```

the function receives:

```python
tenant == "acme"
```

### Why use `Query(...)`?

```python
limit: int = Query(20, ge=1, le=100)
```

- `int` tells FastAPI to parse an integer;
- `20` is the default;
- `ge=1` means greater than or equal to 1;
- `le=100` means less than or equal to 100.

Invalid input is rejected before the function runs.

### Why `async def` and `await`?

The service function is asynchronous, so the route is asynchronous too:

```python
return await list_guided_workflows(...)
```

`await` pauses this request while the asynchronous operation completes. During database or network waiting, the server can work on other requests.

Do not remove `await` from a call to an async service. Without it, you get a coroutine object instead of the service result.

### Why pass keyword arguments?

```python
return await list_guided_workflows(
    tenant=tenant,
    search=search,
    limit=limit,
    offset=offset,
)
```

Names make a call with several similar values easier to read and harder to mix up.

## 2. The feature router adds the shared path

The project's feature router looks like this:

```python
from fastapi import APIRouter

from app.guided_workflows.api.v1 import onboarding, workflow


router = APIRouter(
    prefix="/api/v1",
    tags=["Guided Workflows"],
)

router.include_router(
    workflow.router,
    prefix="/{tenant}/guided_workflows",
)

router.include_router(
    onboarding.router,
    prefix="/guided_workflows/onboard",
)
```

### Why have another router?

Several endpoint files belong to the same feature. This router combines them and supplies shared configuration.

### What does `prefix` do?

FastAPI joins router paths:

```text
feature router:  /api/v1
child prefix:    /{tenant}/guided_workflows
endpoint path:   ""
---------------------------------------------
final path:      /api/v1/{tenant}/guided_workflows
```

If the endpoint used `@router.get("/{workflow_id}")`, the final path would be:

```text
/api/v1/{tenant}/guided_workflows/{workflow_id}
```

### What are `tags`?

```python
tags=["Guided Workflows"]
```

Tags group related endpoints in Swagger. They do not change request behavior.

## 3. `main.py` connects the feature to the application

```python
from app.guided_workflows.api.v1.router import (
    router as guided_workflows_v1_router,
)


app.include_router(guided_workflows_v1_router)
```

### Why rename the import?

Many features export a variable named `router`. The alias tells readers which router this is and prevents name collisions:

```python
router as guided_workflows_v1_router
```

### Why call `app.include_router(...)`?

Creating a router does not automatically register it. `app.include_router(...)` connects its routes to the running FastAPI application.

If this line is missing, requests to those paths return `404`.

## 4. Why have a separate service function?

The route handles HTTP details. The service handles business and data logic.

```python
# API layer
@router.get("/{workflow_id}", response_model=GuidedWorkflowListItem)
async def api_get_guided_workflow(tenant: str, workflow_id: str):
    return await get_guided_workflow(tenant, workflow_id)
```

```python
# Service layer
async def get_guided_workflow(tenant: str, workflow_id: str):
    collection = get_collection(tenant)
    workflow = collection.find_one({"workflow_id": workflow_id})

    if not workflow:
        raise HTTPException(status_code=404, detail="Workflow not found")

    return workflow
```

This separation prevents endpoint files from becoming large mixtures of HTTP parsing, database queries, and business rules.

## 5. This is not FastAPI dependency injection

```python
from app.guided_workflows.services.workflow import get_guided_workflow

return await get_guided_workflow(tenant, workflow_id)
```

This is a normal Python import followed by a normal function call. FastAPI does not create or inject the service.

That distinction matters:

- FastAPI supplies `tenant`, query values, and the request body;
- your route explicitly calls the service;
- the project does not use `Depends(...)`.

## Request flow to remember

```text
GET /api/v1/acme/guided_workflows?limit=20
                       ↓
FastAPI matches the combined router path
                       ↓
FastAPI parses tenant="acme" and limit=20
                       ↓
api_list_guided_workflows(...) runs
                       ↓
await list_guided_workflows(...) runs
                       ↓
response_model validates and serializes the result
```

## Common mistakes

- Forgetting to include a child router or feature router.
- Repeating the entire URL in every endpoint instead of using prefixes.
- Using a path parameter name that does not match the function parameter.
- Forgetting `await` when calling an async service.
- Putting large database queries and business rules directly in the route.
- Calling this direct service import dependency injection.
