# Lesson 6: Module 2 capstone

Build a small `tasks` feature in the style of `customer-success`. Do not add dependency injection, domain exception classes, or unfamiliar abstractions.

## Folder shape

```text
app/
├── main.py
└── tasks/
    ├── api/v1/
    │   ├── router.py
    │   └── task.py
    ├── models/task.py
    └── services/task.py
```

Add `__init__.py` files where Python packages need them.

## Models

Create these Pydantic models:

```python
from typing import Optional


class TaskCreateRequest(BaseModel):
    title: str = Field(min_length=2, max_length=100)
    description: Optional[str] = None


class TaskCreateResponse(BaseModel):
    success: bool
    task_id: str
    msg: str


class TaskListItem(BaseModel):
    task_id: str
    title: str
    description: Optional[str] = None


class TaskListResponse(BaseModel):
    items: list[TaskListItem]
    has_more: bool
```

## Service functions

Implement async functions for:

- create task;
- list tasks with `limit` and `offset`;
- get task by ID;
- delete task by ID.

An in-memory dictionary is enough. Raise `HTTPException(status_code=404, detail="Task not found")` when a task is absent.

## Routers

The parent router must match the project style:

```python
router = APIRouter(prefix="/api/v1", tags=["Tasks"])
router.include_router(task.router, prefix="/{tenant}/tasks")
```

Create these routes:

```text
POST   /api/v1/{tenant}/tasks
GET    /api/v1/{tenant}/tasks
GET    /api/v1/{tenant}/tasks/{task_id}
DELETE /api/v1/{tenant}/tasks/{task_id}
```

Use `response_model` on create, list, and get-by-ID. Use `Query(20, ge=1, le=100)` and `Query(0, ge=0)` for pagination.

## Error boundary

For get and create, use the codebase's boundary:

```python
try:
    return await service_function(...)
except HTTPException:
    raise
except Exception as exc:
    logger.exception("Unexpected task error: %s", exc)
    raise HTTPException(status_code=500, detail="Internal Server Error")
```

Do not send the unexpected exception text to the client.

## App setup

Include the task router in `main.py`. Register `RequestValidationError` using `app.add_exception_handler(...)`. Keep `/swagger` as the docs URL.
