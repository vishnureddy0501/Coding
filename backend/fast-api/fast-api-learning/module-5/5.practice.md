# Module 5 practice

Protect a generic internal products API with signed-request middleware.

Requirements:

1. Require `X-Service`, `X-Timestamp`, and `X-Signature`.
2. Reject timestamps outside a 30-second window.
3. Build the signed message from method, path, timestamp, and body.
4. Verify with a public key and return `401` for an invalid signature.
5. Allow only `/api/service-status/` and `/swagger` without verification.
6. Ensure product queries include the tenant from the URL.
7. Configure CORS separately and explain why it is not authentication.
8. Keep secrets and private keys out of source code and logs.

Before implementing, draw the middleware branches and mark every path that calls `call_next` versus returns an error response.
