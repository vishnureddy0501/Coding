# Module 5: Service authentication and API security

This module focuses on the security style needed to understand an internal FastAPI service: request headers, signed requests, freshness checks, middleware, public paths, secrets, and tenant boundaries.

## Lessons

1. [Authentication, authorization, and trust boundaries](1.security-foundations.md)
2. [Signed internal requests](2.signed-requests.md)
3. [Authentication middleware](3.auth-middleware.md)
4. [CORS, secrets, and safe errors](4.security-practices.md)
5. [Practice](5.practice.md)

Password login, browser sessions, and JWT issuance are not included because they are not necessary for understanding this service-to-service pattern.
