# Lesson 1: The Python FastAPI actually uses

You do not need all of Python before learning FastAPI. You do need to be comfortable with the syntax below because FastAPI reads Python type information to build validation and documentation.

## 1. Values and containers

```python
name = "Vishnu"                         # str
attempts = 3                            # int
price = 99.5                            # float
completed = False                       # bool
description = None                      # absence of a value

tags = ["python", "api"]               # list
task = {"id": 1, "title": "Learn"}     # dict
point = (10, 20)                        # tuple
roles = {"admin", "editor"}            # set: unique values
```

JSON and Python use related but different names:

| JSON | Python |
|---|---|
| object | `dict` or a Pydantic model |
| array | `list` |
| string | `str` |
| number | `int` or `float` |
| boolean | `bool` |
| `null` | `None` |

JSON is text sent over HTTP. A Python dictionary is an in-memory Python object. FastAPI serializes between them; they are not literally the same thing.

## 2. Type annotations

```python
name: str = "Vishnu"
attempts: int = 3
tags: list[str] = ["python", "api"]
task_by_id: dict[int, str] = {1: "Learn FastAPI"}
```

An annotation describes an expected type. Ordinary Python does not enforce it:

```python
attempts: int = "three"  # Python itself allows this assignment
```

Annotations still matter because:

- editors and type checkers can detect mistakes;
- FastAPI uses route annotations to locate, parse, validate, and document inputs;
- Pydantic uses model annotations for runtime validation.

Do not confuse a type hint with validation. Validation happens only when some runtime component—such as Pydantic—reads and enforces the hint.

## 3. Union, nullable, and optional

```python
identifier: int | str
description: str | None
```

`A | B` means either type is allowed. `str | None` means a value may be a string or `None`; this is often called *nullable*.

Whether an argument or model field may be omitted is determined by a default:

```python
description: str | None          # required, but null is accepted
description: str | None = None   # may be omitted; defaults to None
```

Type answers “which values are valid?” Default answers “what happens if no value is supplied?”

## 4. Functions and signatures

```python
def build_message(name: str, excited: bool = False) -> str:
    message = f"Hello, {name}"
    if excited:
        message += "!"
    return message
```

The signature says `name` is required, `excited` may be omitted, and the function claims to return a string. Calls can use positional or keyword arguments:

```python
build_message("Vishnu")
build_message("Vishnu", True)
build_message(name="Vishnu", excited=True)
```

FastAPI route parameters are normal Python parameters. FastAPI prepares their values and calls the function.

### Function object versus function call

```python
build_message             # the function object
build_message("Vishnu")   # call now and obtain its result
```

Frameworks often need the callable itself so they can decide when and how to invoke it.

## 5. Classes, construction, and inheritance

```python
class Task:
    def __init__(self, title: str):
        self.title = title
        self.completed = False


task = Task(title="Learn FastAPI")
print(task.title)
```

A class defines a kind of object, `Task(...)` constructs an instance, `self` is the current instance, and attributes are accessed with a dot.

Pydantic models inherit useful behavior:

```python
from pydantic import BaseModel


class TaskCreate(BaseModel):
    title: str
    completed: bool = False
```

`TaskCreate` inherits construction, validation, and serialization from `BaseModel`.

## 7. Modules, packages, and imports

A `.py` file is a module. A directory containing Python modules is commonly made a package with `__init__.py`.

```text
app/
├── __init__.py
└── main.py
```

```python
from fastapi import FastAPI
from pydantic import BaseModel
```

A path such as `app.main:app` means:

```text
app.main  -> import app/main.py
:app      -> find the variable named app inside it
```

## 8. Dictionary unpacking

```python
body = {"title": "Learn FastAPI", "completed": False}
task = {"id": 1, **body}
```

`**` expands key-value pairs. It can also turn a dictionary into keyword arguments:

```python
task = TaskCreate(**body)
```

That call is conceptually `TaskCreate(title="Learn FastAPI", completed=False)`.

In a dictionary display, a later duplicate key wins:

```python
{"completed": False, **{"completed": True}}
# {"completed": True}
```

## 9. Slicing, loops, and comprehensions

Slicing supports simple pagination:

```python
tasks = ["A", "B", "C", "D"]
offset = 1
limit = 2
page = tasks[offset : offset + limit]  # ["B", "C"]
```

A list comprehension can filter values:

```python
completed_tasks = [task for task in tasks if task.completed]
```

Read it as “for each task, keep it if `task.completed` is true.” Use an ordinary loop if the expression stops being easy to read.

## 10. Exceptions and early exits

```python
def get_task(task_id: int):
    if task_id not in tasks:
        raise KeyError(task_id)
    return tasks[task_id]
```

`raise` stops normal execution. FastAPI's `HTTPException` uses this mechanism to stop a route and create an HTTP error response.
