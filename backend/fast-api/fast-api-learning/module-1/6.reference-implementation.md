# Module 1 reference implementation

Attempt [the capstone](5.practice.md) before reading this file. The purpose of the reference is to resolve misunderstandings, not to replace practice.

## Complete `app/main.py`

```python
from fastapi import FastAPI, HTTPException, Path, Query, Response, status
from pydantic import BaseModel, ConfigDict, Field, field_validator


app = FastAPI(
    title="Task API",
    description="Module 1 FastAPI learning project",
    version="1.0.0",
)


class TaskCreate(BaseModel):
    model_config = ConfigDict(extra="forbid")

    title: str = Field(min_length=2, max_length=100)
    description: str | None = Field(default=None, max_length=500)
    completed: bool = False

    @field_validator("title")
    @classmethod
    def normalize_title(cls, value: str) -> str:
        cleaned = value.strip()
        if len(cleaned) < 2:
            raise ValueError("Title must contain at least 2 non-whitespace characters")
        return cleaned


class TaskUpdate(BaseModel):
    model_config = ConfigDict(extra="forbid")

    title: str | None = Field(default=None, min_length=2, max_length=100)
    description: str | None = Field(default=None, max_length=500)
    completed: bool | None = None

    @field_validator("title")
    @classmethod
    def validate_title(cls, value: str | None) -> str:
        if value is None:
            raise ValueError("Title cannot be null")
        cleaned = value.strip()
        if len(cleaned) < 2:
            raise ValueError("Title must contain at least 2 non-whitespace characters")
        return cleaned

    @field_validator("completed")
    @classmethod
    def completed_cannot_be_null(cls, value: bool | None) -> bool:
        if value is None:
            raise ValueError("Completed cannot be null")
        return value


class TaskResponse(BaseModel):
    id: int = Field(gt=0)
    title: str
    description: str | None
    completed: bool


tasks: dict[int, TaskResponse] = {}
next_task_id = 1


@app.get("/health", tags=["system"])
def health() -> dict[str, str]:
    return {"status": "ok"}


@app.post(
    "/tasks",
    response_model=TaskResponse,
    status_code=status.HTTP_201_CREATED,
    tags=["tasks"],
)
def create_task(body: TaskCreate):
    global next_task_id

    task = TaskResponse(id=next_task_id, **body.model_dump())
    tasks[task.id] = task
    next_task_id += 1
    return task


@app.get("/tasks", response_model=list[TaskResponse], tags=["tasks"])
def list_tasks(
    limit: int = Query(default=20, ge=1, le=100),
    offset: int = Query(default=0, ge=0),
    completed: bool | None = Query(default=None),
):
    items = list(tasks.values())
    if completed is not None:
        items = [task for task in items if task.completed == completed]
    return items[offset : offset + limit]


@app.get("/tasks/{task_id}", response_model=TaskResponse, tags=["tasks"])
def get_task(task_id: int = Path(gt=0)):
    task = tasks.get(task_id)
    if task is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Task not found",
        )
    return task


@app.patch("/tasks/{task_id}", response_model=TaskResponse, tags=["tasks"])
def update_task(
    body: TaskUpdate,
    task_id: int = Path(gt=0),
):
    existing_task = tasks.get(task_id)
    if existing_task is None:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Task not found",
        )

    changes = body.model_dump(exclude_unset=True)
    updated_task = existing_task.model_copy(update=changes)
    tasks[task_id] = updated_task
    return updated_task


@app.delete(
    "/tasks/{task_id}",
    status_code=status.HTTP_204_NO_CONTENT,
    tags=["tasks"],
)
def delete_task(task_id: int = Path(gt=0)) -> Response:
    if task_id not in tasks:
        raise HTTPException(
            status_code=status.HTTP_404_NOT_FOUND,
            detail="Task not found",
        )

    del tasks[task_id]
    return Response(status_code=status.HTTP_204_NO_CONTENT)
```

## Why the important lines exist

`extra="forbid"` detects misspelled or unsupported input fields instead of silently discarding them.

The create title validator strips surrounding whitespace and validates the meaningful content. `Field(min_length=2)` alone sees the original text, so a string containing spaces could otherwise satisfy the length rule.

Every update field has a default, so it may be omitted. Validators reject explicit `null` for fields whose stored output type is not nullable. Description intentionally allows `null` because clearing it is meaningful.

`completed is not None` distinguishes “do not filter” from “filter for incomplete tasks.” A truthiness check would incorrectly ignore `false`.

`exclude_unset=True` distinguishes an omitted update field from a field explicitly sent with a value.

`response_model` validates, serializes, documents, and filters output. The dictionary still stores `TaskResponse` instances so this example's internal state is also easy to reason about.

The delete route returns `Response` directly because `204` must not have a body.

## Deliberate limitations

This reference repeats the `404` lookup and validators in a few places. Later modules will introduce dependencies, services, and cleaner project structure. Adding those abstractions now would make it harder to see the basic route flow.

Likewise, `global next_task_id` and in-memory storage are intentionally temporary. Do not copy them into a real multi-worker service.
