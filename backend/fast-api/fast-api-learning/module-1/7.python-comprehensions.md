# Python comprehensions

A comprehension is a short way to loop over values and create a new collection.

## Basic syntax

```python
[output for item in iterable]
```

Example:

```python
numbers = [1, 2, 3]
squares = [number * number for number in numbers]

print(squares)  # [1, 4, 9]
```

It is the shorter version of:

```python
squares = []

for number in numbers:
    squares.append(number * number)
```

Read this:

```python
[number * number for number in numbers]
```

as: “For every `number` in `numbers`, calculate `number * number` and put it in a new list.”

## Filtering values

Add `if` at the end to keep only matching values:

```python
numbers = [1, 2, 3, 4, 5, 6]
even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)  # [2, 4, 6]
```

## Using `if/else`

Use `if/else` before `for` when every input should produce an output:

```python
labels = [
    "even" if number % 2 == 0 else "odd"
    for number in numbers
]
```

Remember the difference:

```python
# Filters values
[number for number in numbers if number > 3]

# Transforms every value
["big" if number > 3 else "small" for number in numbers]
```

## Dictionary comprehension

```python
names = ["Asha", "Ravi"]
name_lengths = {name: len(name) for name in names}

print(name_lengths)  # {"Asha": 4, "Ravi": 4}
```

## Set comprehension

A set keeps only unique values:

```python
numbers = [1, 1, 2, 2, 3]
unique_squares = {number * number for number in numbers}

print(unique_squares)  # {1, 4, 9}
```

## When to use a normal loop

Use a normal `for` loop when the logic needs multiple steps, logging, error handling, `break`, or `continue`.

The main pattern to remember is:

```python
[what_to_return for one_item in many_items if optional_condition]
```
