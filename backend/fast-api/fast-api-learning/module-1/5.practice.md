# Lesson 5: Module 1 practice

Build a small in-memory task API in one file. Do not add a database, router structure or dependency injection yet.

## Requirements

Create `app/main.py` with:

### Models

`TaskCreate`:

- `title`: required, 2–100 characters;
- `description`: optional, at most 500 characters;
- `completed`: optional, default `False`;
- reject unknown fields.

`TaskUpdate`:

- all fields optional;
- reject unknown fields.

`TaskResponse`:

- `id`: integer;
- all task fields.

### Storage

Use temporary in-memory storage:

```python
tasks: dict[int, TaskResponse] = {}
next_task_id = 1
```

The data may disappear when the server restarts.

### Endpoints

Implement:

```text
GET    /health
POST   /tasks
GET    /tasks
GET    /tasks/{task_id}
PATCH  /tasks/{task_id}
DELETE /tasks/{task_id}
```

The list endpoint should accept:

- `limit`: default 20, minimum 1, maximum 100;
- `offset`: default 0, minimum 0;
- optional `completed` filter.

## Implementation hints

Create a task:

```python
task = TaskResponse(id=next_task_id, **body.model_dump())
```

Apply a partial update:

```python
changes = body.model_dump(exclude_unset=True)
updated_task = existing_task.model_copy(update=changes)
```

Return a missing-resource error:

```python
raise HTTPException(status_code=404, detail="Task not found")
```

For successful deletion, return status `204` with an empty response.

## Manual test cases

Test these through `/docs`:

1. Create a valid task.
2. Create a task without `completed` and confirm it becomes `false`.
3. Try a one-character title and confirm `422`.
4. Send an unknown field and confirm `422`.
5. List tasks with a limit.
6. Filter completed tasks.
7. Retrieve an existing task.
8. Retrieve a missing task and confirm `404`.
9. Update only `completed`; confirm the title remains unchanged.
10. Delete a task and confirm `204`.

## Questions you should answer afterward

1. Why does FastAPI know that `task_id` comes from the path?
2. Why are `limit` and `offset` query parameters?
3. Why is `body` read from JSON?
4. What is the difference between `TaskCreate` and `TaskResponse`?
5. What does `exclude_unset=True` prevent?
6. When does FastAPI return `422`?
7. Why can response validation return `500`?
8. What is the difference between `get_task` and `get_task()`?
9. What does `**body.model_dump()` do?
10. Why is in-memory storage unsuitable for production?
