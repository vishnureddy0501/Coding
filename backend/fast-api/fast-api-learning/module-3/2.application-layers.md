# Lesson 2: Feature-based application layers

## 1. Organize by feature first

```text
app/
├── main.py
├── common/
│   └── logger.py
└── products/
    ├── api/v1/
    │   ├── product.py
    │   └── router.py
    ├── models/
    │   └── product.py
    └── services/
        └── product.py
```

All product code is close together. Adding an orders feature does not make one global routes or services folder enormous.

## 2. Models describe data

```python
from pydantic import BaseModel, Field


class ProductCreate(BaseModel):
    name: str = Field(min_length=2, max_length=100)
    price: float = Field(gt=0)


class ProductResponse(BaseModel):
    product_id: str
    name: str
    price: float
```

Models define request and response shapes. They should not query databases or know about routers.

## 3. API functions handle HTTP concerns

```python
@router.post("", response_model=ProductResponse)
async def api_create_product(store: str, payload: ProductCreate):
    return await create_product(store, payload)
```

The API layer receives validated input and declares the public response.

## 4. Services contain use-case logic

```python
async def create_product(
    store: str,
    payload: ProductCreate,
) -> ProductResponse:
    existing = collection.find_one(
        {"store": store, "name": payload.name}
    )
    if existing:
        raise HTTPException(status_code=400, detail="Product already exists")

    product_id = str(uuid4())
    collection.insert_one(
        {
            "product_id": product_id,
            "store": store,
            "name": payload.name,
            "price": payload.price,
        }
    )
    return ProductResponse(product_id=product_id, **payload.model_dump())
```

The service implements the operation: check uniqueness, create an ID, save the document, and build the result.

## 5. Common code must truly be shared

Place logging or general validation helpers under `app/common`. Keep a helper inside its feature when only that feature uses it.

Do not create a `common` folder as a dumping ground.

## The boundary to remember

```text
model:   What data is valid?
API:     How does HTTP expose the operation?
service: What does the operation do?
common:  What genuinely reusable support is needed?
```
