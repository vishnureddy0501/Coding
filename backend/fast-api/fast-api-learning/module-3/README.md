# Module 3: Structuring a growing FastAPI application

This module explains how to split a FastAPI application into understandable packages. Examples use a generic products feature.

## Outcome

You will understand:

- Python packages and imports;
- feature-based folders;
- router composition;
- models, API, service, and common layers;
- environment configuration;
- the complete request flow through the layers.

1. [Packages and imports](1.packages-and-imports.md)
2. [Feature-based application structure](2.application-layers.md)
3. [Router composition](3.router-composition.md)

5. [Practice](5.practice.md)
