# Module 3 practice

Restructure a small single-file products API into:

```text
app/
├── main.py
├── config.py
├── common/logger.py
└── products/
    ├── api/v1/product.py
    ├── api/v1/router.py
    ├── models/product.py
    └── services/product.py
```

Requirements:

1. Keep Pydantic models in the models package.
2. Keep endpoint decorators and HTTP input in the API package.
3. Keep create, list, get, and delete logic in the service package.
4. Use `/api/v1/{store}/products` as the parent path.
5. Import the feature router into `main.py` with a descriptive alias.
6. Read an optional `APP_NAME` environment variable in `config.py`.

Before running it, write down the import direction and calculate the final URL of every endpoint.
