# Module 4 practice

Build the service layer for a multi-store products API using an in-memory collection-like object first.

Implement:

1. async create, get, list, update, and soft-delete functions;
2. store scope in every read and write query;
3. optional status and escaped name-search filters;
4. an allow-list for `name`, `price`, and `updated_at` sorting;
5. validated `limit` and `offset`;
6. the `limit + 1` technique for `has_more`;
7. a small TTL cache keyed by store.

For each async function, identify which calls are truly awaitable and which are synchronous. If you add a slow synchronous SDK call, isolate it with `asyncio.to_thread`.
