# Microfrontends with Vue.js

Microfrontends apply microservice-style ownership to frontend applications. A large UI is divided into smaller frontend applications that teams can develop, test and deploy independently.

Read in this order:

1. [Microfrontend fundamentals](1.fundamentals.md)
2. [Architecture and Vue integration](2.vue-architecture.md)
3. [Webpack Module Federation](3.module-federation.md)
4. [Interview revision](4.interview-revision.md)

## What you should learn

You should be able to explain:

- why a company would choose microfrontends;
- shell/host and remote applications;
- build-time versus runtime integration;
- route-level and component-level composition;
- independent deployment and team ownership;
- communication without tight coupling;
- shared Vue, router, state and design-system dependencies;
- authentication, routing, CSS isolation and error handling;
- how Module Federation loads remote code;
- when microfrontends add more complexity than value.

Do not begin with Module Federation configuration. First understand the architecture problem it solves.
