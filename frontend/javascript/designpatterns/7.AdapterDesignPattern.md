# 5. Adapter Pattern ⭐⭐⭐⭐

## What Problem Does It Solve?

Sometimes the backend and frontend use different data formats.

The backend sends one structure.

Your React/Vue application expects another.

Instead of changing the data inside every component, create an **Adapter** that converts the backend format into the frontend format.

Think of it like a translator.

```
Backend Format
      │
      ▼
   Adapter
      │
      ▼
Frontend Format
```

---

# Problem

Suppose the backend returns:

```json
{
  "fname": "Vishnu",
  "lname": "Reddy",
  "dob": "2001-01-01"
}
```

But your React component expects:

```javascript
{
  firstName: "Vishnu",
  lastName: "Reddy",
  age: 25
}
```

Without an adapter, every component has to transform the data.

```javascript
const response = await api.get("/user");

const user = {
    firstName: response.data.fname,
    lastName: response.data.lname,
    age: calculateAge(response.data.dob),
};
```

Now imagine you have multiple pages.

```text
User Page

Dashboard

Orders

Settings

Profile
```

Every page repeats the same transformation.

Problems:

- Duplicate code
- Hard to maintain
- Easy to make mistakes
- Every component depends on backend field names

---

# Solution — Adapter Pattern

Create one adapter that transforms the backend response.

**userAdapter.js**

```javascript
export function adaptUser(data) {
    return {
        firstName: data.fname,
        lastName: data.lname,
        age: calculateAge(data.dob),
    };
}
```

Now every component uses the adapter.

```javascript
const response = await api.get("/user");

const user = adaptUser(response.data);

console.log(user.firstName);
```

Your components now work with a consistent frontend-friendly format.

# Project Structure

```text
src/

├── api/
│   └── userApi.js
│
├── adapters/
│   └── userAdapter.js
│
└── pages/
    └── UserProfile.jsx
```

# Why Is This Useful?

Suppose today the backend returns:

```json
{
  "fname": "Vishnu"
}
```

Next month the backend team changes it to:

```json
{
  "first_name": "Vishnu"
}
```

### Without an Adapter

You must update every component.

```text
❌ User Page
❌ Dashboard
❌ Orders
❌ Settings
❌ Profile
```

Lots of work.

Easy to miss one.

---

### With an Adapter

Only one file changes.

```text
Backend Changed

        │
        ▼

Update userAdapter.js

        │
        ▼

Everything Works
```

Your UI remains untouched.



# Benefits

- Keeps components clean
- Removes duplicate transformation code
- Makes backend changes easier to handle
- Creates a consistent data format across the application
- Improves maintainability
