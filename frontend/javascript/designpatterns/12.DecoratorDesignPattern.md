Decorator Design Pattern — Simple Example

Decorator Pattern = add new behavior to an existing object without changing its original code.

A simple example is adding logging to an API service.

1. Original service
class UserService {
    getUser() {
        console.log("Getting user...");
        return {
            name: "Vishnu"
        };
    }
}
2. Decorator
class LoggingDecorator {
    constructor(service) {
        this.service = service;
    }

    getUser() {
        console.log("API request started");

        const result = this.service.getUser();

        console.log("API request completed");

        return result;
    }
}
3. Usage
const userService = new UserService();

const loggedUserService = new LoggingDecorator(userService);

loggedUserService.getUser();

Output:

API request started
Getting user...
API request completed

The original UserService wasn't changed.
