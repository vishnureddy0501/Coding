# 8. Command Pattern

## Problem

Turn an action into an object.

Instead of:

```javascript
deleteUser();
```

Store:

```
Delete Command
```

---

Useful for:

- Undo
- Redo
- Action History

---

## Example

```
Draw
↓
Undo
↓
Redo
```

Applications like Figma use this pattern extensively.
