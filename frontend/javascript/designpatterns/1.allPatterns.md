# Frontend Design Patterns

# Categories of Design Patterns
The most important ones are:

| Category | Patterns |
|----------|----------|
| Creational | Factory, Singleton |
| Structural | Adapter, Facade, Proxy |
| Behavioral | Observer, Strategy, Command, Mediator |

These are the patterns you'll encounter most often in modern frontend applications.

---

# 1. Singleton Pattern

You only want **one instance** of something.

## Rule to Remember
-----------------
✅ Singleton

    export const config = {};
    or
    export default {};
    or
    export const api = axios.create({...});

❌ Not Singleton
    export function createConfig() {
        return {};
    }
    or
    export const getApi = () => axios.create({...});
    
    because every call creates a new instance.
---

Real examples from frontend projects
---------------------------------
These are all effectively Singletons because they export a single instance:

// axios instance
export const api = axios.create({...});

// Redux store
export const store = configureStore({...});

// React Query
export const queryClient = new QueryClient();

// Firebase
export const app = initializeApp(config);

// Socket.IO
export const socket = io("https://...");

They all follow the same idea:
    Create one instance
    Export it
    Import it anywhere
    Everyone shares the same instance

# How to Identify a Pattern

Ask yourself these questions:

### Do I only need one instance?

➡️ Singleton

---

### Am I creating many similar objects?

➡️ Factory

---

### Do many things react to one change?

➡️ Observer

---

### Do I have multiple ways to perform the same task?

➡️ Strategy

---

### Am I simplifying a complex API?

➡️ Facade

---

### Am I converting one data format into another?

➡️ Adapter

---

### Am I controlling access to another object?

➡️ Proxy

---

### Do I need undo/redo or action history?

➡️ Command

---

### Should components communicate through a central hub instead of directly?

➡️ Mediator

# Which Patterns Should a Frontend Developer Master?

| Priority | Pattern | Common Usage |
|----------|---------|--------------|
| ⭐⭐⭐⭐⭐ | Observer | React, Vue, Redux, RxJS |
| ⭐⭐⭐⭐⭐ | Strategy | Authentication, Payments, Validation, Sorting |
| ⭐⭐⭐⭐ | Singleton | API Clients, Auth, Theme, Config |
| ⭐⭐⭐⭐ | Factory | Component Creation, API Clients, UI Libraries |
| ⭐⭐⭐⭐ | Facade | Service Layers, Custom Hooks, API Wrappers |
| ⭐⭐⭐ | Adapter | API Integration, Third-party SDKs |
| ⭐⭐⭐ | Proxy | React Query, Caching, Lazy Loading |
| ⭐⭐ | Mediator | Redux, Event Bus, Complex Component Communication |
| ⭐⭐ | Command | Editors, Undo/Redo Systems |
