# Simple Learning Plan

## Goal

Run a React frontend and FastAPI backend using Docker.

## Day 1

- Understand image and container.
- Learn basic commands.
- Create backend and frontend Dockerfiles.
- Run both with Docker Compose.

## Day 2

- Pass settings safely.
- Understand health checks and logs.
- Learn basic security.
- Deploy, update, and roll back.

## Final flow

```text
Write code
   -> Build an image
   -> Run a container
   -> Test it
   -> Upload image
   -> Run it on the server
```
