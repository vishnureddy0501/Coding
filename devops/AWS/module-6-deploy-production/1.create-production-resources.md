# 1. Create production resources

Create the production equivalents of Module 5:

| Resource | Name |
|---|---|
| EC2 role | `fastapi-prod-ec2-role` |
| Parameter | `/fastapi/prod/app-env` |
| EC2 instance | `fastapi-prod` |
| Security group | `fastapi-prod-sg` |

For the inline role policy, reuse the Module 5 policy with:

```text
<environment> = prod
```

Attach `AmazonSSMManagedInstanceCore` to the role.

Create `/fastapi/prod/app-env` as `SecureString`:

```text
FASTAPI_PRACTICE_APP_NAME=FastAPI Application
FASTAPI_PRACTICE_APP_ENV=production
FASTAPI_PRACTICE_DEBUG=false
MONGO_URL=mongodb+srv://<username>:<password>@<prod-cluster-host>/?retryWrites=true&w=majority
MONGO_DATABASE=fastapi_app_prod
```

Launch a separate Ubuntu EC2 instance and attach the production role. Temporarily allow HTTP `80` from **My IP** so you can verify it before adding the ALB.

Add tags:

```text
Project=fastapi-learning
Environment=prod
```
