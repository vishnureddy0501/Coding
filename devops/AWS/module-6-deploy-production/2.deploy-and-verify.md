# 2. Deploy and verify

Repeat Module 5's installation steps on production, with these changes:

```text
Parameter: /fastapi/prod/app-env
Image:     fastapi-app:v1
Database:  Atlas production database
```

Run the same immutable `v1` image that was tested in development.

## Verify before adding the ALB

Inside EC2:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/ready
curl http://127.0.0.1/health
sudo docker ps
sudo systemctl status nginx --no-pager
```

From your computer:

```text
http://<prod-public-ip>/docs
```

Only continue when `/health` and `/ready` succeed. After the ALB works, Module 7 removes direct public HTTP access to production EC2.
