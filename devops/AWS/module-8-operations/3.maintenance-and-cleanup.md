# 3. Maintenance and cleanup

## Regular maintenance

```bash
sudo apt update
sudo apt upgrade
sudo docker ps
sudo docker images
sudo systemctl status nginx --no-pager
```

Reboot after important system updates, then verify Docker, Nginx, `/health`, and `/ready`.

Before deleting Docker images, inspect `sudo docker images` and keep the current and rollback versions.

## Troubleshooting order

```text
ALB target healthy?
-> EC2 running?
-> Nginx running?
-> Docker container running?
-> /health works locally?
-> /ready reaches Atlas?
-> logs show what error?
```

## Remove the learning environment

Delete in this order:

1. ALB and its listeners.
2. Target group.
3. Dev and prod EC2 instances.
4. Unused EBS volumes and public IPs.
5. Old ECR images and repository when no longer needed.
6. Parameter Store values.
7. CloudWatch alarms and unwanted log groups.
8. IAM roles and security groups after nothing uses them.
9. Atlas Network Access entries for the deleted EC2 IPs.

Finally check **Billing → Bills** in every used Region.
