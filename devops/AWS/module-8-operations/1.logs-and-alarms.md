# 1. Logs, CloudWatch, and alarms

## Check logs on EC2 first

```bash
sudo docker logs --tail 100 fastapi-app
sudo tail -n 100 /var/log/nginx/access.log
sudo tail -n 100 /var/log/nginx/error.log
sudo journalctl -u nginx --since "30 minutes ago"
```

## Send logs to CloudWatch

1. Attach `CloudWatchAgentServerPolicy` to each EC2 role.
2. Open **CloudWatch → Getting started → Set up CloudWatch agent**.
3. Select the managed EC2 instance.
4. Collect `/var/log/nginx/access.log`, `/var/log/nginx/error.log`, and `/var/lib/docker/containers/*/*.log`.
5. Set a short retention period for learning logs.

Use the unified CloudWatch Agent; the older logs-only agent is deprecated.

## Useful alarms

Create only these initially:

| Alarm | Simple condition |
|---|---|
| EC2 CPU | Above 80% for 5 minutes |
| ALB unhealthy host | `UnHealthyHostCount >= 1` |
| Target errors | `HTTPCode_Target_5XX_Count >= 1` |

Send notifications to an email through SNS and confirm the subscription email.

Reference: [AWS CloudWatch Agent](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/Install-CloudWatch-Agent.html)
