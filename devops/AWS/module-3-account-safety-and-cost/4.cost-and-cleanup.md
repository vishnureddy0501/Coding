# 4. Understand and control deployment costs

## What can charge money?

| Resource | When it can charge |
|---|---|
| EC2 | While the instance is running |
| EBS volume | While the volume exists, even if EC2 is stopped |
| Public IPv4 | While the public address is allocated/in use |
| ALB | While the load balancer exists, plus its usage |
| ECR | For stored Docker images |
| Data transfer | Mainly for data leaving AWS |

S3 is postponed for now.

## Important difference

```text
Stop EC2      -> compute charge stops, but EBS can still charge
Terminate EC2 -> instance is deleted; verify attached volumes too
Delete ALB    -> ALB hourly charging stops
```

## Our cost rules

- Use one small dev EC2 and one small prod EC2 only when needed.
- Do not create a NAT Gateway in this course.
- Keep only necessary ECR image versions.
- Create the ALB when learning it; delete it when not needed.
- Check **Billing → Bills** after every practical session.
- Tag resources with `Project=fastapi-learning` and `Environment=dev` or `prod`.

## End-of-session check

```text
EC2 instances: stopped or terminated?
ALB: still required?
Unused EBS volumes: deleted?
Unused public IPs: released?
Old ECR images: required?
```
