# Module 3 — Account safety and cost control

## Goal

Secure the AWS account and receive warnings before costs become surprising.

## Completion checklist

- Root MFA is enabled.
- Daily work does not use the root user.
- A monthly budget and email alert exist.
- `ap-south-1` is the chosen deployment Region.
- You know which resources continue charging when unused.
- No permanent AWS access key is stored in the application.
