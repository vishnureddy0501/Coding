# 5. EC2 role plan

FastAPI will need AWS access later. We will attach an IAM role to EC2 instead of saving AWS keys in `.env`.

```text
FastAPI -> AWS SDK -> EC2 role -> allowed AWS service
```

The role will eventually allow only what the server needs:

- pull the Docker image from ECR;
- read its environment's Parameter Store values;
- connect through Session Manager;
- send selected logs to CloudWatch.

We will create the exact policies in the deployment modules, when the required resources and names are known.

For now, remember:

```text
Human uses admin identity
Application uses EC2 role
Neither stores permanent AWS access keys in the project
```
