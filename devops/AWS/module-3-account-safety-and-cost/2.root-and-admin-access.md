# 2. Secure root and create daily admin access

## Root user

The root user has complete account access. Use it only for account-level tasks.

### Enable root MFA

MFA means **Multi-Factor Authentication**. It requires:

```text
Password + authenticator code/passkey = login
```

If someone steals your password, they still cannot sign in without the second factor.

1. Sign in as the **Root user**.
2. Choose the account name in the top-right corner.
3. Open **Security credentials**.
4. Under **Multi-factor authentication**, choose **Assign MFA device**.
5. Use a passkey/security key when available, or an authenticator app.
6. Complete registration and test the next sign-in.

Keep recovery details safe. Never create root access keys.

## Daily administrator access

For normal learning work, use an administrator identity instead of root.

AWS recommends IAM Identity Center:

1. Open **IAM Identity Center**.
2. Choose **Enable**.
3. Create your user.
4. Create or select the `AdministratorAccess` permission set.
5. Assign your user to this AWS account.
6. Accept the email invitation and enable MFA.
7. Sign out of root and use the AWS access portal from now on.

```text
Root user       -> emergency/account tasks only
Admin identity  -> normal AWS Console work
EC2 role        -> application access to AWS services
```
