# 1. S3 basics

S3 stores files as **objects** inside a **bucket**.

```text
Bucket: fastapi-learning-files
└── Object key: users/123/profile.jpg
    └── Data: image content
```

- **Bucket:** main container for objects.
- **Object:** the stored file and its metadata.
- **Key:** the object's unique name inside the bucket.

Keys may look like folders, but S3 is not a normal disk.

Use S3 for images, PDFs, exports, and attachments. Use MongoDB for users, tasks, orders, and file metadata.

```text
Actual file -> S3
Object key and file details -> MongoDB
```
