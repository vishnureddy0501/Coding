# 3. How FastAPI would use S3 later

## Server upload

```text
User -> FastAPI -> S3 private bucket
```

FastAPI uses its EC2 IAM role. AWS credentials are not stored in `.env`.

## Presigned URL

A presigned URL gives temporary permission for one upload or download:

```text
1. User asks FastAPI for a URL.
2. FastAPI verifies the user.
3. FastAPI creates a short-lived S3 URL.
4. User uploads or downloads directly through that URL.
```

The bucket stays private.

## Future separation

```text
Development -> dev bucket
Production  -> prod bucket
```

We will add `boto3`, IAM permissions, and application code only when the project actually needs file storage.

Reference: [AWS: S3 presigned URLs](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-presigned-url.html)
