# 2. Explore a test bucket

In **S3 → Buckets → Create bucket**:

1. Choose `ap-south-1`.
2. Enter a globally unique name such as `fastapi-learning-<account-id>`.
3. Keep **ACLs disabled**.
4. Keep every **Block Public Access** option enabled.
5. Create the bucket.

Upload a harmless test text file and open its object page.

The object URL should not be publicly accessible. That is correct—the bucket is private.

When finished:

1. Delete the test object.
2. Delete the empty test bucket if you do not need it.

Do not upload secrets or important personal files while experimenting.

Reference: [AWS: create an S3 bucket](https://docs.aws.amazon.com/AmazonS3/latest/userguide/create-bucket-overview.html)
