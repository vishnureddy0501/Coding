# 3. Domain and HTTPS later

The AWS ALB hostname is enough for this course:

```text
http://fastapi-prod-alb-....ap-south-1.elb.amazonaws.com
```

You cannot obtain an ACM certificate for the AWS-owned ALB hostname.

When you buy a domain later:

```text
Domain -> Route 53 DNS -> ALB
ACM certificate -> ALB HTTPS listener :443
ALB HTTP listener :80 -> redirect to HTTPS
```

No application or Docker change is required.
