# 1. Security groups and target group

## ALB security group

Create `fastapi-alb-sg`:

| Direction | Rule |
|---|---|
| Inbound | HTTP `80` from `0.0.0.0/0` |
| Outbound | Allow all |

## Production EC2 security group

Edit `fastapi-prod-sg`:

```text
Remove: HTTP 80 from My IP
Add:    HTTP 80 from fastapi-alb-sg
```

The internet can reach the ALB, but only the ALB can reach production Nginx.

## Target group

In **EC2 → Target Groups → Create target group**:

| Setting | Value |
|---|---|
| Target type | Instances |
| Name | `fastapi-prod-tg` |
| Protocol and port | HTTP `80` |
| VPC | Same VPC as production EC2 |
| Health path | `/health` |
| Success code | `200` |

Register the `fastapi-prod` instance on port `80`.
