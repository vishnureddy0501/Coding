# 4. Install, run, and verify

Run these commands inside the EC2 Session Manager terminal.

## Install software

```bash
sudo apt update
sudo apt install -y docker.io nginx awscli
sudo systemctl enable --now docker nginx
```

## Read configuration

```bash
sudo install -d -m 700 /opt/fastapi
aws ssm get-parameter \
  --name /fastapi/dev/app-env \
  --with-decryption \
  --query 'Parameter.Value' \
  --output text \
  | sudo tee /opt/fastapi/app.env > /dev/null
sudo chmod 600 /opt/fastapi/app.env
```

Add the EC2 public IPv4 address with `/32` to the Atlas dev Network Access list. If the EC2 public IP changes, update Atlas.

## Pull and run

Replace `<account-id>`:

```bash
aws ecr get-login-password --region ap-south-1 \
  | sudo docker login --username AWS --password-stdin <account-id>.dkr.ecr.ap-south-1.amazonaws.com

sudo docker pull <account-id>.dkr.ecr.ap-south-1.amazonaws.com/fastapi-app:v1

sudo docker run -d \
  --name fastapi-app \
  --restart unless-stopped \
  --env-file /opt/fastapi/app.env \
  -p 127.0.0.1:8000:8000 \
  <account-id>.dkr.ecr.ap-south-1.amazonaws.com/fastapi-app:v1
```

## Configure Nginx

Copy the project's `deploy/nginx/fastapi.conf` content into:

```text
/etc/nginx/sites-available/fastapi
```

Then enable it:

```bash
sudo unlink /etc/nginx/sites-enabled/default
sudo ln -s /etc/nginx/sites-available/fastapi /etc/nginx/sites-enabled/fastapi
sudo nginx -t
sudo systemctl reload nginx
```

## Verify

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/ready
curl http://127.0.0.1/health
sudo docker logs fastapi-app
sudo docker inspect --format '{{.State.Health.Status}}' fastapi-app
```

Finally open `http://<dev-public-ip>/docs` from your allowed IP.
