# 3. Launch the dev EC2 instance

In **EC2 → Instances → Launch instance**:

| Setting | Value |
|---|---|
| Name | `fastapi-dev` |
| AMI | Ubuntu Server 24.04 LTS |
| Instance type | A small type shown as Free Tier eligible for your account |
| Key pair | Proceed without a key pair; we use Session Manager |
| IAM instance profile | `fastapi-dev-ec2-role` |
| VPC | Default VPC for now |
| Subnet | A public subnet |
| Auto-assign public IP | Enabled |

Create `fastapi-dev-sg` with:

| Direction | Rule |
|---|---|
| Inbound | HTTP `80` from **My IP** |
| Inbound | No SSH `22` rule |
| Outbound | Allow all |

Use an EBS volume only as large as needed. Add tags:

```text
Project=fastapi-learning
Environment=dev
```

## Connect

Wait until the instance is running, then choose:

```text
Connect → Session Manager → Connect
```

If it is unavailable, verify the IAM role, SSM Agent, and outbound internet access.

Reference: [AWS Session Manager prerequisites](https://docs.aws.amazon.com/systems-manager/latest/userguide/session-manager-prerequisites.html)
