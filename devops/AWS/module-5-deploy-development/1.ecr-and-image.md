# 1. Create ECR and push the image

ECR stores the Docker image. EC2 will pull the same image later.

## Create the repository

In **Amazon ECR → Private repositories**, create:

```text
fastapi-app
```

Keep tag mutability and encryption at their defaults for this learning deployment.

## Build and push

Install and sign in to the AWS CLI locally. From `backend/fast-api/fast-api-app`, replace `<account-id>`:

```bash
aws ecr get-login-password --region ap-south-1 \
  | docker login --username AWS --password-stdin <account-id>.dkr.ecr.ap-south-1.amazonaws.com

docker buildx build \
  --platform linux/amd64 \
  --tag <account-id>.dkr.ecr.ap-south-1.amazonaws.com/fastapi-app:v1 \
  --push .
```

We use `linux/amd64` because the course EC2 instance uses an x86 instance type. Use versioned tags such as `v1`, `v2`; do not depend only on `latest`.

Verify that the `v1` image appears in the ECR repository.

Reference: [AWS: pushing an image to ECR](https://docs.aws.amazon.com/AmazonECR/latest/userguide/docker-push-ecr-image.html)
