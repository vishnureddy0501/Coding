# 2. Create the dev role and parameter

## EC2 role

In **IAM → Roles → Create role**:

1. Select **AWS service → EC2**.
2. Name it `fastapi-dev-ec2-role`.
3. Attach `AmazonSSMManagedInstanceCore` for Session Manager.
4. Add an inline policy using [ec2-deployment-policy.json](assets/ec2-deployment-policy.json).
5. Replace `<account-id>` and `<environment>` with your account ID and `dev`.

This lets EC2 pull the image and read only `/fastapi/dev/*` parameters.

## Parameter Store

Open **Systems Manager → Parameter Store → Create parameter**:

```text
Name: /fastapi/dev/app-env
Type: SecureString
```

Value:

```text
FASTAPI_PRACTICE_APP_NAME=FastAPI Development
FASTAPI_PRACTICE_APP_ENV=development
FASTAPI_PRACTICE_DEBUG=false
MONGO_URL=mongodb+srv://<username>:<password>@<dev-cluster-host>/?retryWrites=true&w=majority
MONGO_DATABASE=fastapi_app_dev
```

Replace the placeholders. Do not commit this value to Git.
