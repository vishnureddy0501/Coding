# 4. Run and verify dev/prod

Run these commands from `backend/fast-api/fast-api-app`.

## Development

```bash
APP_ENV_FILE=.env.development docker compose up --build
```

Verify in another terminal:

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/ready
```

Expected responses:

```json
{"status":"ok","environment":"development"}
{"status":"ready"}
```

Open `http://127.0.0.1:8000/docs` for Swagger UI.

## Production mode locally

Use production configuration but the same image:

```bash
APP_ENV_FILE=.env.production docker compose up --build -d
docker compose logs -f api
```

Stop it with:

```bash
docker compose down
```

## Before deploying to EC2

- Dev and prod use different Atlas databases.
- Atlas Network Access allows the correct EC2 public IP for now.
- No secret is present in Git or the Docker image.
- `/health`, `/ready`, and `/docs` work.
- Nginx is the only public path to port `8000`.

The later EC2 module will replace local environment files with values retrieved from SSM Parameter Store before starting the container.
