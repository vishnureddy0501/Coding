# 3. Docker and Nginx

## Request path

```text
Browser / ALB
      |
      v
Nginx on EC2 :80
      |
      v
Docker port on 127.0.0.1:8000
      |
      v
Uvicorn -> FastAPI
```

Nginx is public-facing on the EC2 server. Port `8000` is bound to `127.0.0.1`, so it is not directly exposed to the internet.

## Dockerfile

The Dockerfile:

- uses Python 3.11, matching `.python-version`;
- installs the exact versions in `uv.lock`;
- runs as a non-root user;
- sends logs directly to Docker;
- includes a `/health` container check;
- runs one Uvicorn process on port `8000`.

One process is enough for our single-instance learning deployment. We can tune workers after measuring real traffic.

## Nginx configuration

Copy `deploy/nginx/fastapi.conf` to `/etc/nginx/sites-available/fastapi` on EC2, enable it, then test and reload Nginx:

```bash
sudo unlink /etc/nginx/sites-enabled/default
sudo ln -s /etc/nginx/sites-available/fastapi /etc/nginx/sites-enabled/fastapi
sudo nginx -t
sudo systemctl reload nginx
```

The configuration forwards the original host, client IP, and protocol to FastAPI and sets simple request timeouts.
