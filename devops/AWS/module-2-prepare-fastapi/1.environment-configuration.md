# 1. Environment configuration

Configuration changes between environments, but application code does not.

| Setting | Development | Production |
|---|---|---|
| `FASTAPI_PRACTICE_APP_ENV` | `development` | `production` |
| `FASTAPI_PRACTICE_DEBUG` | `true` | `false` |
| `MONGO_URL` | Atlas dev connection string | Atlas prod connection string |
| `MONGO_DATABASE` | Dev database | Prod database |

## Prepare the files

From `backend/fast-api/fast-api-app`:

```bash
cp .env.development.example .env.development
cp .env.production.example .env.production
```

Replace the placeholders. Both completed files are ignored by Git.

## Why separate resources?

A development test must never change production records. Therefore dev and prod use separate Atlas databases.
