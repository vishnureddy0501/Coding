# Important Priority Queue Interview Patterns

## 1. Kth Largest Element

Maintain a min heap containing only the `k` largest values seen so far.

```cpp
int findKthLargest(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> minHeap;

    for (int value : nums) {
        minHeap.push(value);

        if (minHeap.size() > k) {
            minHeap.pop();
        }
    }

    return minHeap.top();
}
```

Why a min heap? The smallest of the current `k` largest values is the kth largest overall.

- Time: `O(n log k)`
- Space: `O(k)`

## 2. Kth Smallest Element

Maintain a max heap of size `k`. Its top is the largest among the `k` smallest values.

```cpp
priority_queue<int> maxHeap;

for (int value : nums) {
    maxHeap.push(value);

    if (maxHeap.size() > k) {
        maxHeap.pop();
    }
}

int kthSmallest = maxHeap.top();
```

## 3. Top K Frequent Elements

1. Count each value using a hash map.
2. Store `{frequency, value}` in a heap.
3. Keep only `k` elements or pop the top `k`, depending on the chosen heap.

```cpp
unordered_map<int, int> frequency;

for (int value : nums) {
    frequency[value]++;
}

priority_queue<pair<int, int>> maxHeap;

for (auto [value, count] : frequency) {
    maxHeap.push({count, value});
}
```

Storing frequency first makes it the main priority.

## 4. Merge K Sorted Lists or Arrays

Store the smallest currently available value from every list:

```text
{value, list index, element index}
```

Repeatedly:

1. Remove the smallest value.
2. Add it to the result.
3. Push the next value from the same list.

For `N` total values across `k` lists:

- Time: `O(N log k)`
- Space: `O(k)`

## 5. Dijkstra's Algorithm

Use a min heap of `{distance, node}`:

```cpp
priority_queue<
    pair<int, int>,
    vector<pair<int, int>>,
    greater<pair<int, int>>
> minHeap;

minHeap.push({0, source});
```

Always store the distance first because pair comparison starts with `.first`.

## 6. Running Median

Use two heaps:

```text
Max heap: smaller half of the numbers
Min heap: larger half of the numbers
```

Keep their sizes equal or different by at most one.

- If sizes are equal, the median is the average of both tops.
- Otherwise, the median is the top of the larger heap.

## 7. Scheduling Problems

A heap is useful when the next task depends on the smallest ending time, largest profit, or highest priority.

Common examples:

- Meeting Rooms II
- Task Scheduler
- Single-Threaded CPU
- Maximum Performance of a Team

Before using a heap, ask:

> Which available item must I repeatedly choose next?

That property becomes the heap priority.

## 8. K Closest Points

Keep a max heap of size `k` based on distance. When its size exceeds `k`, remove the farthest point.

You can compare squared distance and avoid calculating square roots:

```cpp
int distance = x * x + y * y;
```

## Choosing the Heap

| Requirement | Useful heap |
| --- | --- |
| Repeatedly remove the largest | Max heap |
| Repeatedly remove the smallest | Min heap |
| Keep the `k` largest values | Min heap of size `k` |
| Keep the `k` smallest values | Max heap of size `k` |
| Process shortest distance first | Min heap |
| Track both halves for a median | Max heap + min heap |

## Interview Checklist

When choosing a priority queue, explain:

1. What each heap element stores
2. Which field determines priority
3. Why a min heap or max heap is required
4. The maximum heap size
5. Time complexity of every push and pop
6. How ties should be resolved
