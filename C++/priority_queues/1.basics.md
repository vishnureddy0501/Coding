# Priority Queue Basics

## What Is a Priority Queue?

A priority queue stores elements in heap order. Unlike a normal queue, removal is based on priority instead of insertion order.

In C++, `priority_queue` is a **max heap by default**:

```cpp
#include <iostream>
#include <queue>
#include <vector>

using namespace std;

priority_queue<int> maxHeap;
```

The largest value is available through `top()`.

## Max Heap

```cpp
priority_queue<int> maxHeap;

maxHeap.push(10);
maxHeap.push(20);
maxHeap.push(5);

while (!maxHeap.empty()) {
    cout << maxHeap.top() << " ";
    maxHeap.pop();
}
```

Output:

```text
20 10 5
```

## Min Heap

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;

minHeap.push(10);
minHeap.push(20);
minHeap.push(5);

while (!minHeap.empty()) {
    cout << minHeap.top() << " ";
    minHeap.pop();
}
```

Output:

```text
5 10 20
```

## Understanding the Min-Heap Syntax

```cpp
priority_queue<DataType, Container, Comparator> name;
```

For this declaration:

```cpp
priority_queue<int, vector<int>, greater<int>> minHeap;
```

- `int` is the type of each element.
- `vector<int>` is the internal container.
- `greater<int>` places the smallest value at the top.

You normally use the default internal `vector` and do not access it directly.

## Important Operations

### `push(value)`

Adds a value:

```cpp
maxHeap.push(10);
```

Time: `O(log n)`

### `emplace(arguments...)`

Constructs an element directly inside the queue:

```cpp
priority_queue<pair<int, int>> heap;
heap.emplace(10, 2);
```

For simple interview code, both `push({10, 2})` and `emplace(10, 2)` are fine.

### `top()`

Returns the highest-priority element without removing it:

```cpp
int value = maxHeap.top();
```

Time: `O(1)`

Do not call `top()` on an empty priority queue.

### `pop()`

Removes the top element:

```cpp
maxHeap.pop();
```

Time: `O(log n)`

`pop()` does not return the removed value. Read it first:

```cpp
int value = maxHeap.top();
maxHeap.pop();
```

### `empty()` and `size()`

```cpp
if (maxHeap.empty()) {
    cout << "Heap is empty";
}

int count = maxHeap.size();
```

Both take `O(1)`.

## Complexity

| Operation | Complexity |
| --- | --- |
| `top()` | `O(1)` |
| `push()` | `O(log n)` |
| `emplace()` | `O(log n)` |
| `pop()` | `O(log n)` |
| `empty()` | `O(1)` |
| `size()` | `O(1)` |

Building a heap by inserting `n` values individually takes `O(n log n)`. Constructing from an existing range can build the heap in `O(n)`.

## Common Mistakes

- Forgetting that the default is a max heap
- Calling `top()` when the heap is empty
- Expecting `pop()` to return a value
- Using a max heap when an algorithm needs the minimum first
- Assuming iteration order is sorted—the priority queue exposes only its top
