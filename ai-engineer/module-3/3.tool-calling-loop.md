# Lesson 3: The tool-calling loop

The Responses API may return a function call instead of a final answer. Your application executes it and sends the result back.

## 1. First model request

```python
from openai import AsyncOpenAI


client = AsyncOpenAI()


response = await client.responses.create(
    model=model_name,
    instructions=TOOL_ROUTER_INSTRUCTIONS,
    input=user_question,
    tools=TOOLS,
    parallel_tool_calls=False,
)
```

`model_name` should come from application configuration. `parallel_tool_calls=False` keeps the first implementation sequential and easier to control.

## 2. Find function calls

```python
function_calls = [
    item
    for item in response.output
    if item.type == "function_call"
]
```

Each function-call item contains:

- `name`: proposed tool name;
- `arguments`: JSON string proposed by the model;
- `call_id`: identifier used to attach the result to this call.

The proposal has not executed anything.

## 3. Execute and return the result

```python
conversation_input = [
    {"role": "user", "content": user_question},
    *response.output,
]

for tool_call in function_calls:
    result = await execute_tool(
        tool_name=tool_call.name,
        raw_arguments=tool_call.arguments,
        context=context,
        data_service=data_service,
    )

    conversation_input.append(
        {
            "type": "function_call_output",
            "call_id": tool_call.call_id,
            "output": result.model_dump_json(),
        }
    )
```

The same `call_id` tells the model which result belongs to which request.

## 4. Ask for the grounded answer

```python
final_response = await client.responses.create(
    model=model_name,
    instructions=GROUNDED_ANSWER_INSTRUCTIONS,
    input=conversation_input,
    tools=TOOLS,
    parallel_tool_calls=False,
)

answer = final_response.output_text
```

The second request contains the original question, the model's function-call item, and your function-call output.

## 5. Limit the loop

A model can request another tool after receiving the first result. Use an application counter:

```python
MAX_TOOL_CALLS = 2
tool_call_count = 0
```

Before every execution:

```python
if tool_call_count >= MAX_TOOL_CALLS:
    return no_information_response()

tool_call_count += 1
```

This limit prevents an uncontrolled chain of operations. It is enforced by application code, not by asking the model politely.

## Important concept

Tool calling is a loop coordinated by your code:

```text
model proposes → application validates → application executes
→ model receives evidence → model produces answer
```

The model never directly calls Python, MongoDB, or your internal API.
