# Module 1: Define the chatbot's exact scope

Do not begin with a model, vector database, or chat UI. First define exactly what the chatbot may answer and which project data may support those answers.

## Outcome

After this module, you should be able to:

- inventory your approved data sources;
- define supported users, entities, and question types;
- distinguish `answered`, `no_information`, and `out_of_scope`;
- identify questions that require a live API/database tool versus document retrieval;
- create a scope contract used by implementation and evaluation.
