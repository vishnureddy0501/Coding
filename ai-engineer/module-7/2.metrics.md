# Lesson 2: Metrics and failure analysis

Track:

| Metric | Meaning |
|---|---|
| Status accuracy | Correct public outcome |
| Intent accuracy | Correct operation selected |
| Argument accuracy | Correct account ID and limit |
| Answer correctness | Facts match live tool result |
| Source correctness | Source matches executed operation |
| Unsupported claims | Claims absent from tool output |
| Authorization leaks | Forbidden data exposed |
| Latency | End-to-end response time |

Two important errors:

```text
false acceptance = answered an unsupported/unsafe question
false refusal    = refused a valid question with available evidence
```

Investigate in order:

```text
scope decision
→ selected tool
→ validated arguments
→ authorization filter
→ live database/API result
→ final answer and sources
```

Fix the layer that failed rather than changing the final prompt for every problem.
