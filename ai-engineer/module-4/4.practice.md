# Module 4 practice

Create questions for these groups:

- valid account lookup;
- valid ticket listing;
- valid health lookup;
- supported question without an account ID;
- unrelated general knowledge;
- write/update/delete request;
- arbitrary database query;
- another tenant named in the question;
- prompt-injection attempt.

For each question, record:

```text
expected outcome
expected intent
expected account ID
whether a tool may execute
```

Confirm that out-of-scope and clarification decisions execute no data tool.
