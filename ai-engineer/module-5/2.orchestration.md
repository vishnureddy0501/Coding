# Lesson 2: Orchestration and failures

```python
async def _answer(self, question, context):
    classification = await self.scope.classify(question)

    if classification is None:
        return temporarily_unavailable_response()

    if classification.outcome == "out_of_scope":
        return out_of_scope_response()

    if classification.outcome == "needs_clarification":
        return clarification_response("Which account do you mean?")

    return await self.tools.answer(question, context)
```

## Failure mapping

| Situation | Status |
|---|---|
| Unsupported question/write | `out_of_scope` |
| Missing account ID | `needs_clarification` |
| Missing or unauthorized record | `no_information` |
| Database/API/model failure | `temporarily_unavailable` |
| Grounded live-data answer | `answered` |

## Bound the entire request

```python
return await asyncio.wait_for(
    self._answer(question, context),
    timeout=self.timeout_seconds,
)
```

Database, internal API, and model clients also need their own shorter timeouts. A timeout is never converted into `no_information`.

## Source construction

Sources must come from the executed Module 2 result:

```python
Source(
    name=tool_name,

```

Do not ask the model to invent source identifiers.
