# Module 5 practice

Create `/api/v1/chat` and manually run:

1. A valid account lookup.
2. A valid open-ticket request.
3. A valid account-health request.
4. A missing account ID.
5. An account outside the user's permission scope.
6. An unrelated question.
7. An unsupported update request.
8. A simulated database/API timeout.

Inspect status, answer, and sources. Confirm that tenant and role never come from the request body.
