# Lesson 3: Deployment reference

## Configuration

```python
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", extra="ignore")

    openai_api_key: str
    answer_model: str
    classifier_model: str
    mongo_url: str
    account_api_url: str
    chat_timeout_seconds: int = 15
    maximum_tool_calls: int = 2
```

Commit `.env.example` with variable names only.

## Startup

```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    settings = Settings()
    app.state.chat_orchestrator = create_chat_orchestrator(settings)
    yield
    await close_shared_clients(app.state.chat_orchestrator)
```

Create database, HTTP, and model clients once and close them during shutdown.

## Container

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir .
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

Use the project's lock file, non-root container user, and deployment standards in the real service.

Start with one internal role, three read operations, bounded traffic, monitoring, and an easy disable switch.
