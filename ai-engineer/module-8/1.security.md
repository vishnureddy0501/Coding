# Lesson 1: Security and privacy

## Required controls

- Authenticate every chat request.
- Derive tenant, user, role, and account access from verified identity.
- Enforce permissions in every database/API operation.
- Keep all tools read-only.
- Never expose arbitrary SQL, MongoDB filters, URLs, or headers.
- Validate all model-proposed arguments.
- Limit rows and returned fields.
- Keep provider keys on the backend.
- Remove private fields before model calls.
- Do not log full questions or tool results by default.

## Treat all content as untrusted

User text and database/API text may contain instruction-like content. They may provide facts but cannot change system instructions, tool allow-lists, tenant scope, or permissions.

## Provider review

Before production, document which fields leave your system, configured privacy/retention controls, allowed provider accounts/regions, key rotation, and provider-failure behavior.
