# Lesson 2: Reliability and observability

Bound:

- entire chat-request duration;
- database, internal API, and model calls;
- retry count;
- concurrent requests;
- maximum two tool calls;
- returned rows and fields;
- question and evidence size.

Retry only temporary failures. Do not retry invalid arguments, authorization failures, or out-of-scope questions.

## Structured log fields

```text
request ID
safe tenant/user identifiers
scope outcome and intent
tool name, duration, and result count
model and prompt versions
token use and latency
final response status
timeout/retry count
```

Avoid logging credentials, full tool output, and sensitive customer fields.

## Investigation order

```text
scope classification
→ tool selection
→ argument validation
→ authorization and live query
→ result truncation
→ grounded answer
```
