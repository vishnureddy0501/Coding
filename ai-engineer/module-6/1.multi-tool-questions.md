# Lesson 1: Multi-tool live-data questions

Example:

```text
Show account-101's status and current health.
```

This may require:

```text
get_account(account-101)
get_account_health(account-101)
```

Module 3 already caps execution at two tool calls. Combine results only when both use the same trusted context and account.

```python
if account_result.status != "found":
    return no_information_response()

if health_result.status != "found":
    return no_information_response()
```

Do not partially invent the missing half. You may return a partial answer only if your product contract explicitly allows and labels partial results.

## Parallel or sequential?

Start sequentially because it is easier to inspect and limit. Parallel calls are useful only when operations are independent and your application still enforces a combined call limit.

## Truncated results

If tickets return `has_more=True`, the answer must say it is based on the returned subset. Do not say “all open tickets.”
