```python
async def resolve_question(payload, context, conversation_store):
    question = payload.question

    if payload.conversation_id is None:
        return question

    state = await conversation_store.get(
        conversation_id=payload.conversation_id,
        tenant=context.tenant,
        user_id=context.user_id,
    )

    if state is None:
        return question

    if refers_to_previous_account(question) and state.last_account_id:
        return f"{question}\nReferenced account ID: {state.last_account_id}"

    return question
```

## Two-operation aggregation

```python
async def get_account_overview(context, account_id, data_service):
    account = await data_service.get_account(context, account_id)
    if account.status != "found":
        return account

    health = await data_service.get_account_health(context, account_id)
    if health.status != "found":
        return health

    return {
        "account": account,
        "health": health,
    }
```

This is an application-defined composition of two approved operations, not arbitrary model access.
