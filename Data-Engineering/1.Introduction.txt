it contains 3 layers
    1. Data Production
    2. Data Transformation
    3. Data serving


OLTP:
-----
Online Transactional Processing
Efficient for writes, updtes.
we use Data Modelling (Normal Forms) here.

eg: sql, mysql, postgress sql.

these databases managed by database administrations. 
data engineers don't need to learn much about this.

OLAP:
----
online analytical processing

these are called as data warehouses.

efficient for reads.

we use dimensional techique in OLAP databases.

example: snowflake, wherehouse red.



OLTP to OLAP 
------------

OLTP  -----------------------> ETL ----------------> OLAP

extract                    Transform                  Load


Data Warehouse layers:
----------------------
1. staging
2. core


staging is of 2 types
1. Transient (temporary)
2. persistent (permanent)


Incremental Loading:
-------------------
Data Fetching Strategy from OLTP to OLAP
